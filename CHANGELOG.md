# Changelog

## 0.1.4 - Keywell Portraits and Actor Corrections

- Added packaged portraits for all seven Keywell Hag Encounter actors and their prototype tokens.
- Converted Harald's divine abilities into true D&D5e Spell items so they appear in the Spells section.
- Retained Harald's dawn-recovery daily limits and one tracked Resurrection Diamond.
- Added packaged images for War Golem Mk I, Mk II, and Mk III and repaired their source actor references.
- Added packaged artwork for all four Resurrection Diamond grades and repaired their item references.
- Added module-local image validation to the repository validation gate.
- Added suggested hag-house and clearing dimensions to the encounter documentation.

## 0.1.3 - Keywell Hag Encounter and Resurrection Diamonds

- Added the `Etesia: Keywell Hag Encounter` actor compendium.
- Added Mother Sallow, the Hollowoak Guardian, and a reusable Memory Bundle objective actor.
- Added Edric Vale, Mara Vale, Edric's Bloodied Horse, and an encounter-specific Harald support actor.
- Rebuilt Harald as an NPC field healer with 2024-style healing values, dawn-recovery limited uses, Sanctuary, Prayer of Healing, Gentle Repose, Revivify, breastplate, shield, and a healer's satchel.
- Added standard, Consecrated, Sovereign, and Perfect Resurrection Diamond items to `Etesia Items`.
- Established one standard Resurrection Diamond for Revivify while leaving higher-grade substitution ratios provisional.
- Added save-based actions, legendary actions, encounter objectives, and GM-facing tactical notes for a reduced level-8 party.
- Added `docs/encounters/keywell-hag-encounter.md` and `docs/items/resurrection-diamonds.md`.
